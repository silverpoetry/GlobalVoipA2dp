# Code of Conduct

This community expects professional, respectful, and evidence-based collaboration. Contributors of
all experience levels and backgrounds are welcome. Harassment, discrimination, personal attacks,
doxxing, or intentional distribution of unsafe builds is not accepted.

Technical disagreements should focus on reproducible logs, framework behavior, code, and tests.
Maintainers may edit or remove content that violates these expectations and may restrict accounts
that repeatedly disrupt collaboration.

Report community-conduct concerns privately through the repository owner's available GitHub contact
or security-reporting channel.
